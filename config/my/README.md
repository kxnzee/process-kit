# Личные настройки и инициализация

Модель веток и доступа — [OWNERSHIP.md](../../docs/OWNERSHIP.md). Ниже описан формат и применение данных этого каталога.

EXAMPLE.json показывает полный набор полей, которые может заполнить pp-ai-init.
Это заготовка с TODO, а не готовый рабочий конфиг. Скопируй её в config/my/config.json
и материализуй только нужные части. Не переносить командные записи в личный слой.

| Поле | Что делает инициализация |
|---|---|
| schemaVersion | Оставляет 2 |
| profile.name / email | Сохраняет подтверждённую локальную Git-идентичность; не выдумывает и не читает глобальные секреты |
| teamId | Выбранный team.id, либо null при ответе «Без команды»; название команды хранится в team |
| storage.mode | local — только компьютер, repository — собственный репозиторий |
| storage.repositoryUrl | Только при repository: подтверждённый адрес remote mine, отличный от origin; при local поле удаляется |
| taskStores / codeStores | Только собственные подключения; структура показана полностью, id my-tasks/my-code можно изменить |
| defaults.taskStore / codeStore | Выбор по id личной или командной записи, без копирования самой записи |
| defaults.project / repository | Необязательный выбранный ресурс; repository имеет вид projectKey/slug |
| preferences | Только уже согласованные переносимые предпочтения; при инициализации допустим {} |

## Что заполняется всегда

Выбранная команда/отсутствие команды, подтверждённая идентичность пользователя и
вариант хранения. Локальные настройки Git выводятся из этих значений и сверяются
с ними, но не являются вторым источником выбора. Абсолютные пути checkout не сохраняются.

## Что заполняется по необходимости

При personal-only не запрашиваются будущие подключения: удали обе учебные записи,
оставь taskStores/codeStores=[] и defaults={}. Не оставляй TODO вместо выбранной команды
или storage.mode. При live заполняй только нужные личные подключения; если используются
командные, личные массивы остаются пустыми, а defaults ссылаются на командные id.
Неиспользуемые поля defaults удаляются. Учебные подключения не включаются автоматически.

При смене default-подключения прежний командный default его ресурса не наследуется.
teamId=null отключает командный слой. Чужой id команды и повтор id подключения — ошибка.
Файл не переносится в team/master. Параметры соединений описаны в
[настройках команды](../team/README.md). Секреты хранятся в клиенте.
