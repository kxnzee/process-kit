# Копирование контекста team

Скопируй всю эту папку в context/team/<тема>/, заполни CONTEXT.md и убери подстановки. Имя темы — латиница, цифры и дефисы; префикс уровня не нужен. Папка example не загружается как рабочие сведения.

Процесс объявляет уровень team в requires.context; загрузчик включает его рабочие темы в каталог. Для аргумента экшена (например styleFile) укажи точный путь context/team/<тема>/CONTEXT.md. Ничего не подключается по наличию файла.

Заголовок задаёт тему; назначение — потребителя, сведения — факты/термины/содержательные правила, источники — основания и дату, ограничения — неизвестность и срок применимости. Не добавляй настройки подключения, секреты, маршруты или команды скиллов.
