# Проверить существующую личную настройку

Вход: setup-status с personal.state=invalid/incomplete/outside-personal, known и issues. Существующая копия
или её настройки обнаружены; эта ветка не разрешает создавать новую my и заменять
конфиг с нуля. Сначала объясни конкретное расхождение и сохрани уже известные выборы.

| issues | Действие агента |
|---|---|
| open-existing-personal-copy | Личная копия уже есть; проверь несохранённые изменения. Предложи открыть её и дождись согласия на переключение. |
| personal-config-missing | Личная ветка есть, конфиг отсутствует. Проверь доступные подтверждённые сведения; уточни только отсутствующие значения для восстановления файла. |
| personal-config-invalid | Не удалось безопасно прочитать/проверить конфиг. Укажи файл, не цитируй сырую ошибку. Не перезаписывай его; объясни необходимость проверки или согласованного восстановления. |
| selected-config-unavailable | Проверь выбранный командный слой и его соответствие сохранённому выбору. Не заменяй выбор команды автоматически. |
| local-profile-mismatch | Сверь сохранённый профиль с локальной подписью Git. Объясни расхождение; согласуй конкретное изменение, не спрашивай все данные заново. |
| local-hooks-missing | Объясни необходимость восстановить локальную защиту; после согласия используй hooks-install, сохраняющий прежние hooks. |
| custom-hooks-path | Обнаружен пользовательский путь hooks. Не меняй его; согласуй установку защиты с владельцем. |
| personal-push-mismatch | Сверь локальную защиту отправки с выбранным storage. Не меняй хранение, remote или upstream молча. |
| personal-history-missing | Основание копии не подтверждено. Останови изменения и объясни, какой проверки истории не хватает. |

Не запрашивай повторно known.team, known.storage и известный профиль. Неполнота
защиты не делает эти выборы неизвестными. Не передавай технические команды человеку:
сам выполни разрешённые проверки, затем запроси только нужное решение.
Если нет согласия на исправление, ограничься выводами. Для согласованного восстановления
используй инструменты существующих настроек и hooks-install, без удаления чужих файлов,
stash/reset, смены команды или основания личной копии. Не исправляй tools/ или tests/.

После конкретного исправления снова вызови setup-status. Переход к настройке подключений
выполняет агент по новому результату; не загружай план создания личной копии.
Если изменялись настройки, проверку и отчёт выполни по .gigacode/skills/pp-ai-init/references/save-settings.md этой папки.
