# Эталон: папка outputs/

## Правило

Один запуск — одна папка outputs/<ГГГГ-ММ-ДД>_<коротко>/.
- <коротко>: 1–4 слова строчными через дефис, до 40 символов, только буквы, цифры,
  дефис; без пробелов и точек.
- Повтор имени — суффикс -2, -3. Существующая папка не перезаписывается.
- Прямо в outputs/ только папки. Подпапок по видам нет.
- Результат последнего шага процесса — в папке запуска вторым файлом; файл шага есть
  у каждого шага, включая последний, в её .run/. Ничего не копируется из .run/.
- Чистка по сроку (runs_keep_days) удаляет только .run/ в старых папках.

Зарезервированные имена:

| <коротко> | Что | Есть сейчас |
|---|---|---|
| настройка | отчёт настройки | да |
| заявка-команда-<код> | заявка администратору на команду | да |
| заявка-подключение-<система> | заявка разработчику на подключение | да |
| проба-<задача> | пробный прогон на тестовых данных | да, режим демо |
| обновление | будущее «обнови Process Kit» | нет |
| поделиться-<процесс> | будущее «Поделись с командой» | нет |
| сборка-<процесс> | будущая сборка процесса в экстеншен | нет |

## Дерево

```
outputs/
├── 2026-10-29_настройка/
│   └── что-сделано.md
├── 2026-10-29_сводка-просрочки/
│   ├── итог.md
│   ├── сводка.md
│   └── .run/
│       ├── run.md
│       ├── trace.jsonl
│       ├── state.json
│       └── 01-jira-search.json
├── 2026-10-29_сводка-просрочки-2/
│   └── …
├── 2026-10-29_проба-сводка-просрочки/
│   └── …
└── 2026-10-30_заявка-подключение-confluence/
    └── заявка.md
```

Нет .run/ в папках настройки и заявки. Нет файлов с пробелами в имени.

## .run/

- Файлы шагов: <NN>-<имя шага>.<расширение>: 01-jira-search.json,
  02-compose-report.md. Файл шага есть у каждого шага, включая последний: полный след
  прогона живёт только здесь.
- Результат последнего шага тот же шаг пишет вторым файлом в папку запуска. Копировать,
  переносить и переименовывать файл из .run/ нельзя.
- state.json после каждого завершённого шага:

```json
{ "last_step": 1, "last_step_name": "jira-search",
  "params": { "период": "7d" }, "updated": "2026-10-29T15:31:04" }
```

- run.md — журнал прогона: процесс, уровень, режим, значения параметров, маршрут,
  артефакты, остановки и их причины.
- trace.jsonl — журнал вызовов, строка на вызов.

## .history/runs.jsonl

Одна строка на запуск, обязательно поле output:

```json
{"ts":"2026-10-29T15:30:00","process":"overdue-summary","уровень":"общий","режим":"живой","output":"2026-10-29_сводка-просрочки","итог":"готово"}
```

Поле `итог` дословно повторяет строку «Чем закончилось» из `итог.md`; `уровень` —
общий, командный или личный; `режим` — живой или демо.

## Пути

- Тексты (скиллы, GIGACODE.md): ROOT=$(git rev-parse --show-toplevel) только в
  разделе «Где лежат результаты» GIGACODE.md.
- Код (tools/, pre-push): ROOT только в tools/paths.js.
- В чате всегда полный путь: «Результат: …», «Отчёт о настройке: …», «Заявка: …».
- outputs/ и .history/ не входят в манифесты процессов, «Поделись с командой» и сборку
  экстеншена. git ls-files outputs .history — пусто.
