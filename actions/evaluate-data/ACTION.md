# Вычислить данные по правилу

## Аргументы

- inputs — объект: имя аргумента → путь JSON-файла; процесс передаёт сохранённые артефакты явно.
- rulesFile — точный путь к локальному JS-модулю правила процесса с экспортом evaluate(inputs, parameters). Это проверенный код репозитория, не инструкция или скрипт из данных внешней системы.
- parameters — объект аргументов правила, {} допустим. Обязательные параметры определяет правило.
- resultContract — точный путь к JSON-контракту результата у владельца правила.

## Выполнение

1. Проверь пути, типы аргументов, наличие входов и схему результата. Не подбирай правило по имени процесса.
2. Загрузи JSON-входы без изменения. Вызови evaluate(inputs, parameters) из переданного rulesFile. Правило — синхронная чистая функция: не делает внешних вызовов и не пишет файлы. Его дополнительные файлы перечислены в экспорте files.
3. Проверь полученный объект по resultContract. Не меняй формулу и не подставляй значения из соседнего примера.
4. Верни data. При save локальная проверка повторяет вычисление и отклоняет подменённый результат.

Неверный вход, отсутствующее правило, неподдерживаемая схема или ошибка вычисления блокируют шаг с причиной. Экшен не знает предметную область, названия групп и формулы конкретного процесса; не оформляет документ.
