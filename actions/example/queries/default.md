# Запрос: чтение выбранных записей

Образец описания запроса для передачи экшену kind=source; скопируй в processes/<имя>/queries/<запрос>.md. Локальный transform из ACTION.md этот файл не использует. При адаптации сначала определи систему, подтверждённые параметры и контракт результата; незаполненные условия не разрешают живой вызов.

## Параметры

| Параметр | Тип и источник | Обязательность |
|---|---|---|
| queryFile | Точный путь файла запроса в папке процесса | Обязателен, задаётся явно |
| taskStore | id записи taskStores из config/ | Явный выбор или defaults.taskStore |
| project | Подтверждённый ключ проекта выбранного подключения | Обязателен для этого образца |

## Правила отбора

Читай только записи явно выбранного проекта. Конкретные типы, статусы и дополнительные фильтры укажи при адаптации по требованиям процесса; не угадывай их по соседнему запросу.

## Чтение и полнота

Используй реальные операции адаптера выбранного taskStore. Обработай все страницы с учётом лимитов. Недоступность, ошибку и неполную выдачу отмечай явно: они не означают отсутствие записей.

## Результат

При адаптации перечисли поля записи и согласуй их с consumes/produces и contracts экшена. Верни прочитанные факты; бизнес-классификацию, расчёт показателей и оформление отчёта выполняют отдельные экшены. Этот образец не задаёт готовый результат.
