# Одиночное локальное действие

Вход: выбранное действие, фактические входы, ожидаемый результат и область поручения.
Если имя не определено, подбери одну подходящую операцию по ACTION.md и проверь контракт.
При обязательном/подходящем формальном процессе применяй его по GIGACODE.md.
Штатная разовая работа GigaCode не обязана оборачиваться в Action.

1. Прочитай ACTION.md. Если это source/act или одного действия недостаточно, сообщи
   ограничение; агент рассматривает Process или его создание. Не запускай цепочку.
2. Уточни отсутствующие входы. Личная настройка и подключения для local transform не нужны.
3. Подготовь spec и вызови `node tools/kit.js action <spec.json>`. Временный JSON создай
   через JSON.stringify/json.dump в системной временной папке; удали после вызова, включая ошибку.
   Для edit-text: action=edit-text, mode=local, inputText — фактический текст,
   params.режим — подтверждённый режим, например «коротко».
4. При needs-model прочитай рецепт, подготовь результат и повтори вызов с теми же входами
   и value. Ошибку проверки не подменяй успехом; не меняй инструменты ради обычной задачи.
5. Покажи проверенный результат. Для согласованного сохранения укажи resultFile в новой
   папке outputs/<дата>_<имя>/. Старое не перезаписывай. Не создавай Run Journal и не вызывай finish.

Результат: проверенное значение, путь при сохранении и ограничения. Без Run Journal
не обещай восстанавливаемость процесса. Завершение Action завершает только его часть
поручения; агент продолжает остальное в разрешённой области.
