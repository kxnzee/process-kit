# Адаптер: Example System (kind = `example`)

Копируемая заготовка адаптера системы задач. Здесь описывается технический способ
доступа: операции, параметры, ответы и ограничения. Запросы, критерии оценки,
формулы и оформление отчёта передаются вызывающим процессом через экшен.

Example System — учебное название. Реальное подключение и инструменты не назначены;
живое выполнение заблокировано до заполнения и проверки сопоставления операций.
При создании адаптера замени название и kind на фактические значения.

## Подключение

MCP-сервер: значение taskStores[].mcpServer выбранной записи config/.
Выбор записи делает вызывающий экшен по taskStore; адаптер не выбирает первую запись
и не подставляет конкретное имя сервера. Адрес берётся из baseUrl этой записи.
Для адаптера кода используй codeStores/codeStore вместо taskStores/taskStore.
Секреты в адаптере не хранятся; настройки клиента содержат ссылки $secret.

## Операции

| Capability | Инструмент | Тип | Вход | Результат |
|---|---|---|---|---|
| readRecords | Не назначен: сопоставить с реально объявленным инструментом | read | Описание запроса, его аргументы, параметры страницы по фактической схеме | Записи, признаки полноты и продолжения по фактической схеме |

readRecords — учебное имя возможности, не имя существующего MCP-инструмента.
Заменяй всю строку фактическим сопоставлением. Для каждой нужной операции укажи
точное имя инструмента, обязательные параметры, форму ответа, лимиты и ошибки.
Имена операций и параметры берутся из реально доступных схем, а не из этой заготовки.
Если сервер или нужная операция недоступны — остановка с причиной; другой источник
не подставляется. Запись во внешнюю систему допускается только экшеном kind=act
с соответствующим согласием; этот образец описывает только чтение.

## Пагинация и полнота

Механизм страниц пока не проверен. До живого использования опиши фактические поля
курсора/смещения, признак последней страницы, лимит и возможное усечение ответа.
Все необходимые страницы должны быть прочитаны. Успешный пустой полный ответ,
ошибка, усечение и недоступное поле — разные исходы. Без подтверждения полноты
нельзя утверждать отсутствие записей. Не назначай неизвестному полю пустое значение.

## Поля и нормализация ответа

Сопоставление полей пока не заполнено. До использования перечисли необходимые
исходные поля и их типы, соответствие контракту вызывающего экшена, правила дат,
идентификаторов, статусов и обработки отсутствующих значений. Сохраняй основания
и признаки полноты. Не добавляй вычисленные бизнес-признаки в данные чтения.

## Ограничения и ошибки

Права, лимиты запросов, размер пакета и поддерживаемые фильтры пока не подтверждены.
Зафиксируй их по фактической системе. Ошибки доступа и сети сообщаются явно;
не повторяй неизвестный результат внешнего изменения автоматически.

## Пробный прогон

В demo внешних вызовов нет. Экшен читает только явно переданный dataFile процесса
по своему входному контракту; структура демоданных принадлежит экшену/процессу,
а не этому адаптеру. Демо не подтверждает доступность сервера и корректность
фактического сопоставления полей API.

## Статус проверок

| Что проверяется | Статус и основание |
|---|---|
| Подключение и перечень реальных инструментов | Не проверено: учебная заготовка |
| Сопоставление параметров и полей ответа | Не проверено: требуется заполнение |
| Пагинация, полнота и ошибки доступа | Не проверено: требуется проверка реальной системы |

Подтверждённый факт сопровождай датой, средой/версией и свидетельством без секретов.
До заполнения обязательных сведений адаптер не объявляется готовым к живому запуску.
