# Общие defaults

В этой папке хранится config.json с безопасными общими значениями по умолчанию:
лимит глубины запусков и резерв defaults. Команд, серверов, адресов, репозиториев
и выбранных подключений на этом уровне нет — их место в team/my.

Формат полей, приоритет уровней и проверки описаны в общей инструкции
[Настройки master / team / my](../team/README.md), раздел «master».

Общий файл входит в снимок любого прогона, включая local/demo; изменение лимита
требует нового прогона, team/my не переопределяют execution. Проверка значений:
`node tools/kit.js check --only sources`.
