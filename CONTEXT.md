# Process Kit

## Термины

**Процесс**: повторяемый маршрут решения рабочей задачи из переиспользуемых действий.

**Действие**: один шаг с определёнными входами, результатом и границами ответственности.

**Подключение**: доступ к конкретной внешней системе. Объединяет способ обращения и сведения о том, где находятся данные.

**Контекст**: факты, термины и предпочтения, помогающие понимать задачу; не заменяет её инструкции.

**Уровень владения**: область ответственности за процесс и связанные материалы: общая, командная или личная.

**Прогон**: одно выполнение процесса с заданными параметрами и сохранённым результатом.

**Артефакт шага**: проверяемый результат действия, который можно передать следующему действию.

**Пробный прогон**: выполнение на вымышленных данных без обращений к рабочим системам и без внешних изменений.

**Перенос изменений**: предложение выбранных изменений владельцам уровня для проверки и принятия. Сам по себе не публикует процесс для всех.
