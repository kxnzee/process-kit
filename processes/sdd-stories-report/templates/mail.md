# Письмо по историям без SDD

Создай только готовое тело письма, без темы и списка получателей — их добавляет
prepare-mail-draft из mail-data. Источник — только переданный JSON mail-data.

Укажи период meta.window. Коротко попроси уточнить причины отсутствия SDD и дальнейшие
действия. Перечисли все stories: ключ, summary, responsible и url. Не добавляй истории,
выполненные по SDD, непроверенные или исключённые. Не делай вывод о нарушении процесса
без дополнительных оснований и не обещай конкретные сроки от имени адресатов.
При meta.demo=true добавь «ДАННЫЕ ДЕМО». Не отправляй письмо.
