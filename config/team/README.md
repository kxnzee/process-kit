# Настройки master / team / my

Модель веток и доступа — [OWNERSHIP.md](../../docs/OWNERSHIP.md). Ниже описан формат и применение данных этого каталога.

Командные настройки создаются из config/team/EXAMPLE.json.

Инициализация сохраняет рабочее окружение, чтобы человек не задавал его при каждой задаче.
Секреты остаются в хранилище клиента. Настройки читаются только через tools/lib/config/config.js;
потребители получают вычисленное представление без записи объединённого файла.

```text
config/
  master/
    config.json
  team/
    EXAMPLE.json
    config.json          # реальные данные только в team-* и у наследующей my
  my/
    EXAMPLE.json
    config.json          # реальные данные только в личной копии
```

## master

Содержит безопасные общие defaults версии 2. Проверки структуры находятся в tools/lib/config/config-contract.js. Реальных команд, серверов, адресов,
репозиториев и выбранных подключений в этом уровне нет.

| Поле master | Назначение |
|---|---|
| schemaVersion | Версия 2 |
| defaults | Пустой резерв общих defaults; подключения и ресурсы задаются team/my |
| execution.maxProcessDepth | Положительное целое: максимум одновременно активных процессов, включая корневой; 5 по умолчанию, 1 запрещает вложенные вызовы |

Лимит используется загрузкой зависимостей, preflight и выполнением, а не только
хранится в JSON. Общий конфиг входит в снимок любого режима, включая local/demo.
Изменение лимита требует нового прогона. team/my не переопределяют execution.
EXAMPLE.json — заготовки, а не активные настройки. Они доступны во всех ветках.

## team

Скопируй config/team/EXAMPLE.json в config/team/config.json в рабочей ветке команды.
Заполни team.id (код команды без team-), team.name и team.owners (список ответственных).
Добавь taskStores и codeStores: id, adapter, mcpServer, displayName, kind, enabled,
baseUrl и технические координаты экземпляра. Для репозиториев — projectKey, slug,
defaultBranch и при необходимости url. Адаптер указан как adapters/<имя>/ADAPTER.md.

Остальные поля подключения определяет его адаптер; незаполненное нужное поле блокирует
живой процесс. Шаблонные подключения выключены; включай после заполнения.
Непроверенные capabilities и лимиты не считай подтверждёнными только из-за наличия в шаблоне.

Общие сведения команды и ресурсы хранятся здесь один раз. Личный конфиг их не копирует
и не изменяет. Абсолютные пути локальных checkout не относятся к команде.

## my

Скопируй config/my/EXAMPLE.json в config/my/config.json в личной копии.

| Поле | Назначение |
|---|---|
| schemaVersion | 2 |
| profile | Подтверждённые name/email пользователя; заполняются при инициализации |
| storage | Выбранное хранение local/repository и repositoryUrl только для repository |
| teamId | Код выбранной команды, совпадает с team.id; null — работа без команды |
| taskStores / codeStores | Только собственные подключения с уникальными id; не копии командных |
| defaults | Личный выбор taskStore/codeStore и при необходимости project/repository |
| preferences | Переносимые личные предпочтения; не локальное состояние компьютера |

teamId=null явно отключает наследованную team даже при наличии её файла. Если указана
команда, а файл отсутствует или принадлежит другой команде, происходит остановка.
Изменение teamId не переключает ветку и не скачивает настройки другой команды:
смена основы личной копии — отдельная миграция.

## Приоритет и ресурсы

Явный аргумент запуска → личный default → командный default → общий default.
Слияние разрешено только для известных полей defaults: taskStore, codeStore, project,
repository. Массивы подключений объединяются по уникальным id; повтор id запрещён.
Личная запись не может переопределить адрес или состав командной записи.

Выбор подключения по умолчанию используется, только если экшену не передан id.
project и repository — сохранённый выбор ресурса. Экшен чтения использует такой
выбор только для соответствующего default-подключения и только если запросу не
передан явный параметр project/repository. Доступный командный каталог не меняется.
repository задаётся как projectKey/slug; project — ключ проекта выбранного taskStore.
Выбранные значения проверяются относительно соответствующего подключения.

Реальный config/team/config.json наследуется из team-* и не редактируется настройкой
личной копии. config/my/config.json не переносится в team/master. Ссылки и локальные
настройки Git определяются по текущей копии. Идентичность команды находится в team,
выбор пользователя — в my.teamId. Других источников выбора команды нет.

## Инициализация и проверка

`node tools/kit.js config --json` показывает разрешённые настройки с происхождением записей; файлы не меняет.

С командой: выбрать team-* по team.id/name → создать my от неё → записать teamId
и личные defaults. Без команды: создать my от стабильного тега → teamId=null →
сохранить собственные подключения. Personal-only тоже сохраняет выбранную команду,
но не требует подключений, MCP и секретов. Существующие файлы не перезаписываются.

node tools/kit.js check --only sources — структура и значения слоёв.
node tools/kit.js check --only connections — ссылки на адаптеры и выбранные id.
Перед live — --process <имя>; проверяются только нужные выбранные подключения.
Снимок live включает использованные слои и схемы; изменение настроек запрещает
продолжать старый прогон. Demo не требует реальных слоёв или MCP.


## Поля подключений в team и my

Одинаковая форма записи не означает копирование записи между уровнями.

| Поле | Назначение |
|---|---|
| id | Уникальный идентификатор во всех активных слоях и типах подключений |
| kind | Подтверждённый технический тип системы |
| adapter | Путь adapters/<имя>/ADAPTER.md |
| mcpServer | Имя реально подключённого сервера; не значение доступа |
| enabled | Boolean; false запрещает выбор подключения для live |
| displayName | Название для человека |
| baseUrl | Базовый адрес веб-интерфейса |
| issueUrlTemplate / pullRequestUrlTemplate | Правило построения ссылки, а не конкретный секретный адрес |
| projects / issueTypes | Доступные ключи проектов и типы задач данной системы |
| statusesExclude | Статусы исключения; конкретный отбор задаёт запрос процесса |
| modules[].name / code | Общие сведения о КЭ: имя и код; [] означает отсутствие фильтра КЭ для текущего SDD-процесса |
| repositories[].projectKey / slug / defaultBranch / url | Координаты репозитория, основная ветка и необязательная ссылка |
| acceptTargetBranches | Приёмные ветки; критерии конкретной проверки принадлежат процессу |
| capabilities | Заявленные возможности, не доказательство доступности инструмента |
| limits.jqlMustIncludeIssueType | Требуется ли тип задачи в JQL на данной инсталляции |
| limits.getIssuesBatchMax / pageSize | Подтверждённые размер пакета / страницы |
| pullRequest.pageSize | Размер страницы PR для данного подключения |
| pullRequest.keyExtraction.fields / pattern / ignorePatterns | Поля и выражения связывания PR с задачами; используются адаптером по выбранному запросу |
| comment | Пояснение, не исполняемое правило |
