---
name: prepare-mail-draft
description: Готовит черновик письма без отправки и без обращения к системам
kind: transform
adapter: none
consumes:
  artifacts: [report-text]
  params: [to, subject]
produces:
  mail-draft: черновик письма
contracts:
  mail-draft: text
---

# Черновик письма

1. Тело — из обязательного report-text, получатели — ровно из to, тема — из subject.
   Не создавай и не переписывай содержание тела: сборка текста — предыдущий шаг.
2. Если to ссылается на поле артефакта, прочитай его, убери дубли и пустые значения.
   Имена без адресов оставь именами; почтовые адреса не выдумывай.
3. Нет получателей — спроси человека. Не выполняй новые запросы к системам.
4. Верни mail-draft с получателями, темой и телом, статусом «черновик».
   В поставке почтового подключения нет. Ни согласие, ни название действия не
   разрешают отправку. Для реальной отправки нужно отдельное act-действие с
   адаптером, проверенным контрактом и подтверждением точного внешнего изменения.
