# Как понимать задачи (классификация)

> Пожелание владельца личного уровня, а не настройки и не контекст прогона: этот файл читает
> шаг по своему рецепту и исполняет наравне с файлом правил. Движок Process Kit файл не
> открывает, не проверяет и в его содержании не разбирается.

Данные действия `classify-issuance` — решение владельца рабочего места, которое рецепт
шага (`ACTION.md`) исполняет наравне с файлом правил. Это не общий контекст прогона:
файл читается только этим шагом и только для классификации задач инфо-поводов.

## Как отнести задачу к технической или содержательной

- **Сначала смысл, потом признаки.** Задачу читают и понимают: изменится ли у читателя
  что-то в данных, методах, поведении, составе источников. Решение принимается по этому
  пониманию, с цитатой из текста задачи как основанием.
- **Правила и поиск слов — это сверка, а не сам ответ.** Правила нужны, чтобы решение
  не потерялось между прогонами и чтобы то, что уже решено командой, не обсуждалось
  заново. Совпадение регулярного выражения без смысла — не решение.
- **Примеры уже принятых решений.** «Устранение уязвимостей библиотек (SCA)» —
  техническая. «Вывод новой реплики самообслуживания» — содержательная: для читателя это
  новые данные, даже если в тексте нет слова «данные». «Настройка загрузчиков» рядом с
  изменением схемы не делает задачу технической: содержательное изменение схемы важнее.
- **Не уверен — не угадываю.** Задача остаётся в отчёте с пометкой и вопросом человеку.
  Ошибочное «техническая» прячет повод, ошибочное «содержательная» засоряет отчёт; оба
  хуже, чем честный вопрос.
- **Расхождение смысла и правила видно в отчёте.** Оно не решается молча ни в одну сторону.

## Материал для оценки

- Для смысла задачи разрешено (и ожидается) чтение связанных задач и комментариев: связь
  релиз → стори, связанные задачи внедрения, обсуждение. Ссылки и номера инцидентов в
  отчёт не переносятся — только смысл.
- Сеть и системы: только чтение. Ничего не комментируется и не правится в системе задач
  по ходу классификации.
