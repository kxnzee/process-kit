# Сохранение текста

Вход: непустая строка text. Сохрани её посимвольно в единственном поле text результата. Кавычки, переводы строк и другие символы экранируются средствами JSON без изменения значения строки. Выход — объект по contracts/result.json. Пустой текст или иной тип — ошибка входа. Новые поля и факты не добавляются.
