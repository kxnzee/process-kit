# Рассчитать SDD

1. Прочитай task-records, code-evidence и rules/<rule>.md. Входы должны принадлежать
   одному отбору и содержать уникальные ключи; чужие/повторные ключи кода — ошибка.
2. Примени assessSdd из tools/sdd-data.js: сопоставление только по key, метка ИЛИ
   подтверждённый MERGED PR с путём под watchPath. Никаких запросов к системам.
3. Для отрицательного вывода нужны оба полностью проверенных отрицательных признака.
   Нет свидетельства — unverified с причиной. Группы взаимно исключаются.
4. Рассчитай счётчики один раз по итоговым группам; не читай fetch.json/expected
   и не заимствуй показатели из текста или входных метаданных.
5. Верни report-data по docs/reference/artifacts.md. Текст/шаблон отчёта не читай;
   в источники не обращайся и входные свидетельства не изменяй.
