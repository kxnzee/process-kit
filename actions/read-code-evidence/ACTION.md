# Прочитать свидетельства кода

## Аргументы

- task-records — сохранённый входной артефакт: records с уникальными key и selectionId; полный контракт входных данных — contracts/task-records.json. Получи именно переданный набор, не ищи последний прогон.
- queryFile — обязательный точный путь processes/<владелец>/queries/<имя>.md от корня. Запрос определяет область поиска, связывание задач с PR и нужные факты; соседний запрос не подбирается.
- codeStore — id существующего подключения к коду; явный выбор или defaults.codeStore из разрешённых настроек, прочитанных через tools/lib/config/config.js.
- parameters — обязательный объект параметров запроса, {} допустим. Требования определяет сам запрос; пути, ветки, статусы и критерии конкретного процесса здесь не зашиты.
- dataFile — необязательные вымышленные входы, только для demo.

Эффективные параметры проверяются по contracts/input.json. Входные данные не изменяются.

## Выполнение

1. Проверь входной набор и его идентификатор, аргументы и обязательные параметры запроса. Прочитай точный queryFile и адаптер выбранного codeStore. Ключи получи только из переданных records.
2. Собери факты о связанных PR и изменениях кода через реальные инструменты адаптера. Область поиска и способ связывания задай по запросу. Пагинация и батчи — внутренние операции; не пропускай страницы и не расширяй отбор задач.
3. Для каждого входного ключа верни запись: key, prs (если прочитаны), prsComplete, commits и commitsComplete (если запрос задаёт поиск коммитов вне принятых PR), commit (если подтверждён), reason (при неполноте). У PR — id/url, нормализованный state, changedPaths при доступности; у коммита — hash, branch, changedPaths при доступности. Неизвестные значения не заменяй пустыми списками.
4. prsComplete=true означает, что вся заданная запросом область поиска по PR пройдена и результаты чтения полны. Только тогда prs=[] подтверждает отсутствие PR в этой области. commitsComplete=true означает то же для области коммитов: только тогда commits=[] подтверждает отсутствие привязанных коммитов. Ошибки доступа, пропущенные страницы и отсутствие фактов дают prsComplete=false или commitsComplete=false с причиной; полностью недоступное подключение блокирует операцию.
5. Сохрани selectionId из task-records без изменения и queryFile текущего вызова. Выход соответствует contracts/result.json. Чужие и повторные ключи запрещены; отсутствующие входные ключи считаются непроверенными, а не отрицательным результатом.
6. В demo не обращайся к системам. evidenceFromFixture из tools/lib/actions/code-data.js принимает вымышленные codeEvidence, сохранённые task-records и точный queryFile; проверяет совпадение пути, ограничивает факты входными ключами и связывает их с текущим selectionId. Не читай расчёты или результаты оценки.

## Границы и ошибки

Экшен возвращает факты и полноту чтения. Не решает, удовлетворяет ли задача критериям процесса, не вычисляет показатели и не оформляет отчёт. Неверные аргументы, изменённый вход и чужой запрос — остановка с причиной. Недостающие факты явно отмечаются без домысливания.
