# Прочитать задачи

1. Прочитай точный queries/<query>.md и адаптер выбранного taskStore. Иной файл
   не подставляй. Выполни только отбор и чтение полей задач, объявленные запросом.
2. Пагинация и батчи — до исчерпания данных, с сохранением фактических счётчиков
   чтения. Дубликаты объектов по key объединяй без потери свидетельств.
3. Недоступный сервер — остановка; непроверенное поле/история — явная причина,
   не ложное отрицательное значение. Не подменяй сервер или данные.
4. В demo читай только раздел задач выбранной фикстуры; сеть запрещена.
5. Сформируй selectionId через tools/sdd-data.js по готовому содержимому отбора.
   Верни task-records по docs/reference/artifacts.md. Не читай код/PR, не дели
   истории на SDD-группы, не считай проценты, не дочитывай текст готового отчёта.
   Это единственная операция и единственный выход этого действия.
